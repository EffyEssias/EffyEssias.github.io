# Effy's portfolio

Portfolio of Fernando Espessoto Dias (Effy), Roblox UI/UX designer.
Live at https://effyessias.github.io/

A static site: plain HTML, CSS and JavaScript, no build step. Open `index.html` in a browser to view it locally.

- `index.html`: home page (about, works, process, career, contact)
- `brookhaven.html`: Brookhaven UI redesign case study
- `css/site.css`, `js/site.js`: styles and interactions
- `images/`, `fonts/`: pictures and self-hosted fonts
